고등학교 「인공지능 기초」(김현철 외 4인, 2022 개정 교육과정) 교과 연계 상호작용형 가상 실험실입니다.

**MVP 1 · 탐색 실험실** — 교과서 Ⅰ-02 인공지능과 탐색 (인쇄 26~41쪽)
**MVP 2 · 데이터 실험실 + 최근접 이웃** — 교과서 Ⅱ-01 (67~81쪽), Ⅱ-02 (108~109·114쪽)
**MVP 3 · 회귀 실험실** — 교과서 Ⅱ-02 (94~103쪽)
**MVP 4 · 분류 실험실** — 교과서 Ⅱ-02 (106~115쪽)

이 문서의 모든 쪽수는 **학생이 보는 인쇄 쪽수** 기준입니다. (PDF 쪽 = 인쇄 쪽 + 2)

교과서는 학생을 여러 외부 시뮬레이터로 보냅니다 — 8퍼즐 게임(28쪽), TensorSpace(63쪽),

교과서 용어로 통합**하는 도구입니다. 코랩·오렌지3를 대체하지 않고 **그 앞의 0단계**에 놓입니다.

## 시작하기

Node.js 20 이상이 필요합니다. 터미널에서 이 폴더로 이동한 뒤:

```bash
npm install     # 처음 한 번만
npm run dev     # 개발 서버 실행 → 주소가 표시됩니다 (보통 http://localhost:5173)
```

수업에 배포할 파일을 만들 때:

```bash
npm run build   # dist 폴더에 정적 파일이 생성됩니다
npm run preview # 만들어진 결과를 확인
```

`dist` 폴더 안의 파일을 그대로 올리면 됩니다. **서버 프로그램이 필요 없습니다.**

### 배포 위치에 따른 설정

`vite.config.ts`의 `base` 한 줄만 바꾸면 됩니다.

| 배포 위치 | `base` 값 |
|---|---|
| 학교 서버 최상위 (`https://ai-lab.학교.kr/`) | `'/'` (현재 설정) |
| GitHub Pages (저장소 이름이 `ai-lab`) | `'/ai-lab/'` |
| USB·공유 폴더에서 `index.html` 직접 열기 | `'./'` |

라우팅에 주소의 해시(`#/bfs`)만 쓰기 때문에 서버 쪽 리다이렉트 설정이 필요 없습니다.

### 세 알고리즘이 한 파일인 이유

너비 우선·균일 비용·A*는 **“오픈 리스트에서 하나를 고른다”는 뼈대가 같고 고르는 기준만
다릅니다.** `bestFirst.ts`의 `pickIndex()` 함수 한 곳이 그 차이의 전부입니다.

- `g`만 보면 → 균일 비용 탐색
- `h`만 보면 → 탐욕적 최상 우선 탐색
- `g + h`를 보면 → A* 탐색

교과서 36쪽 옆단의 설명이 코드 구조 그대로입니다. 수업에서 이 부분을 화면에 띄워
보여 주셔도 좋습니다.

### 제너레이터를 쓴 이유

`runSearch()`가 제너레이터라서, **한 단계 실행 · 자동 실행 · 되돌리기 · 스냅샷**이
알고리즘 코드를 건드리지 않고 전부 해결됩니다. 되돌리기는 저장된 단계 배열의
인덱스를 1 줄이는 것이 전부입니다.

MVP 5의 k-평균(교과서 119쪽 6단계)과 MVP 6의 신경망 학습도 같은 구조를 재사용합니다.

## 수업에서 쓰실 때

### 학습 모드

화면 오른쪽 위 `학습 모드` 옆에서 바꿉니다. 옆의 `[?]` 를 누르면 학생에게도 설명이 표시됩니다.

- **자유 실험** (기본) — 모든 설정을 자유롭게 조작합니다. 평소에는 이 상태로 두시면 됩니다.
- **안내 실험** — ① 예상하기를 마쳐야 실행 버튼이 열립니다.
  학생이 결과를 먼저 보고 나서 예상을 맞춰 쓰는 것을 막기 위한 모드입니다.
  여는 조건은 두 가지이고, 잠겨 있을 때 실행 버튼 아래에 무엇이 남았는지 표시됩니다.
  - 예상 보기 중 하나를 고를 것
  - 그렇게 생각한 이유를 3바이트 이상 적을 것 (한글 한 글자 = 3바이트)

  조건을 바꾸시려면 `src/experiments/search/SearchLabScreen.tsx` 의 `canRun` 과
  `src/ui/InquiryPanel.tsx` 의 `guidedDone` 을 함께 고치시고,
  `npm run gate` 로 확인하십시오.
- **도전 과제** — MVP 6에서 추가됩니다. 그때까지는 버튼이 보이지 않습니다.

### 교사용 보기 — 주소로만 켜집니다

학생 화면에는 켜는 버튼이 **나타나지 않습니다.** 주소 뒤에 `?teacher=1` 을 붙여 한 번 여시면
그 브라우저에 기억됩니다.

```
https://아이디.github.io/저장소이름/?teacher=1
```

끄실 때는 화면 오른쪽 위의 `[교사용 보기 끄기]` 또는 `?teacher=0` 을 쓰시면 됩니다.

교사용 보기에는 **예시 답안**이 함께 나옵니다. ① 예상하기 · ⑤ 설명하기 · 더 생각해 볼 질문의
답안을 질문 바로 아래에서 확인하실 수 있어, 학생과 답을 맞춰 보실 때 화면을 그대로 쓰시면 됩니다.

발문·오개념·예시 답안 문구는 모두 `src/teacher/searchTeacher.ts` 한 파일에 모여 있습니다.

> **한계를 분명히 말씀드립니다.** 이것은 가림막이지 잠금장치가 아닙니다.
> 정적 사이트라 주소를 아는 학생은 켤 수 있습니다. 반드시 가려야 하는 내용(예: 지필평가 문항)은
> 이 화면에 두지 마십시오. 실제로 차단하시려면 학생용과 교사용을 **별도 저장소로 나누어 배포**해야 합니다.

또한 **학생이 입력한 답변은 그 학생의 기기에만 저장됩니다.** 교사 화면에서 반 전체의 답변을
모아 볼 수는 없습니다. 교사용 보기의 '이 기기의 입력'은 지금 쓰고 있는 브라우저에 저장된
내용만 보여 줍니다. 학생 답변을 함께 보시려면 학생 화면을 프로젝터에 띄우시면 됩니다.

### 학생 기록

실습실 공용 컴퓨터를 고려해 **기본 저장소는 브라우저를 닫으면 사라지는 방식**입니다.
앞 반 학생이 적은 내용이 다음 반에 보이지 않습니다.

- `[이 기기에 저장]` — 학생이 직접 눌러야만 기기에 남습니다 (경고 후 진행)
- `[내 기록 지우기]` — 모든 화면 상단에 항상 있습니다. 수업 종료 시 누르도록 안내해 주세요

## 교과서와 다른 점 · 미리 알아 두실 것

### 1. 8퍼즐에서 빈칸을 옮기는 순서

교과서 **37쪽 활동 3**은 위 → 아래 → 왼쪽 → 오른쪽,
교과서 **29쪽 그림**은 위 → 왼쪽 → 아래 → 오른쪽으로 순서가 다릅니다.

이 앱은 **37쪽 기준**을 씁니다. 순서가 달라지면 같은 알고리즘이라도 탐색 순서가 달라지므로,
학생이 교과서와 다른 결과를 얻었다고 하면 이 부분을 확인해 주세요.
`src/core/search/puzzle.ts`의 `DEFAULT_DIRECTION_ORDER`에서 바꿀 수 있습니다.

### 2. 너비 우선 탐색은 비용을 보지 않습니다

같은 도시 지도에서 너비 우선 탐색은 `a–b–e`(비용 14)를, 균일 비용 탐색은
`a–c–d–e`(비용 12)를 찾습니다. **이 차이가 이 단원의 핵심**이므로,
너비 우선 탐색에는 “더 싼 경로를 찾으면 값을 바꾸는” 처리를 넣지 않았습니다.
(구현 중 이 규칙이 잘못 적용되어 두 탐색의 결과가 같아지는 문제가 있었고, 검증 테스트로 잡았습니다.)

### 3. 교과서 32쪽 그림의 간선 b–d = 8

PDF 텍스트만으로는 확정할 수 없어 확인 후 반영했습니다. 최적 경로에는 영향이 없습니다.

### 4. 계산 방식

이 실험실의 계산은 **전부 브라우저에서 실제로 수행**합니다. 미리 만들어 둔 결과를
보여 주는 방식이 아닙니다. 8퍼즐의 너비 우선 탐색만 안전을 위해 3,000개까지 테스트하고
멈추며, 이 경우에도 “상태 수가 많을수록 탐색 시간이 늘어난다”는 안내를 보여 줍니다.

### 합성 데이터

`src/data/penguins.json` 은 교과서 원본을 복제하지 않고 **같은 속성 이름과 통계 특성을 재현해
새로 만든 교육용 데이터**입니다. `npm run data` 로 다시 만들 수 있고, 씨앗값이 고정되어 있어
항상 같은 데이터가 나옵니다. 학생마다 통계값이 달라지면 교사용 발문의 예상 답도 흔들리기 때문입니다.

맞춘 값: 344행 / 종별 152 · 68 · 124 / 부리 길이 평균 43.9 / 부리 깊이 17.0 / 날개 길이 200.8 /
체질량 4198 / 날개 길이 ↔ 체질량 상관 0.89 / 결측치 10행 → 334 / 성별 `.` 1행 → 333.

> **교과서 80쪽 수치 참고.** 아델리펭귄이 168마리로 적혀 있으나 세 종을 더하면 360이 되어
> 총 344와 맞지 않습니다. 152 + 68 + 124 = 344 이므로 152로 생성했습니다.
> 학생이 교과서와 다른 숫자를 발견하면 이 점을 알려 주십시오.

### 체질량 이상치는 종별로 보아야 보입니다

전체를 한 덩어리로 보면 젠투펭귄이 원래 무거워서 이상치가 잡히지 않습니다.
종별로 나누어 상자그림을 그려야 턱끈펭귄의 이상치 2개가 드러납니다.
이 자체가 좋은 발문 소재라 화면도 종별 상자그림으로 만들었습니다.

## MVP 3 · 회귀 실험실

| 화면 | 내용 | 교과서 |
|---|---|---|
| 3-1 훈련 데이터와 테스트 데이터 | 비율 슬라이더 · 무작위 재분할 · 산점도에서 두 데이터 구분 | 94, 100쪽 |
| 3-2 과적합 | k 값에 따른 훈련·테스트 정확도 2선 그래프 | 95쪽 |
| 3-3 선형 회귀 | 점 추가·이동·삭제 · 회귀선 즉시 재계산 · 오차 세로선 · MSE/MAE/RMSE/R² · 다중 회귀 | 96~103쪽 |

3-1 과 3-2 는 펭귄 데이터를 이어서 쓰고, 3-3 은 신체 치수 데이터를 씁니다.

### 신체 치수 합성 데이터

`src/data/body.json` · 300행 · 목둘레 · 몸무게 · 엉덩이둘레 · 허리둘레.
목둘레 → 허리둘레 단순 회귀의 R² 가 **0.73** 으로 교과서 값(약 0.72)과 거의 같습니다.
속성을 늘린 다중 회귀는 0.77 로 올라갑니다. `npm run data:body` 로 다시 만들 수 있습니다.

### 수업에서 가장 인상적인 장면

- **3-2** — k 를 1로 놓으면 훈련 정확도가 거의 100%인데 테스트 정확도는 93% 입니다.
  "훈련 정확도 100%가 좋은 신호가 아니다"를 두 선의 간격으로 한눈에 보여 줍니다.
- **3-3** — `[지금 값을 기준으로 저장]` → `[이상치 하나 넣기]` 순서로 누르면
  네 지표의 변화량이 함께 표시됩니다. MSE 만 크게 뛰는 것이 바로 보입니다.
- **3-3 심화** — 이상치를 **x 의 평균 자리**에 놓으면 기울기가 전혀 변하지 않고 절편만 움직입니다.
  최소제곱법의 성질을 학생이 직접 발견하게 하는 좋은 질문입니다.

## MVP 4 · 분류 실험실

| 화면 | 내용 | 교과서 |
|---|---|---|
| 4-1 결정트리 | 트리 ↔ 산점도 양방향 연동 · 지니 계수 · 최대 깊이 · 깊이별 비교표 | 107, 112쪽 |
| 4-2 로지스틱 회귀 | 클래스별 확률 · 확신의 정도를 배경색 진하기로 표현 | 114쪽 |
| 4-3 모델 비교실 | 세 모델 결정 영역 나란히 · 혼동 행렬 · 정밀도와 재현율 | 106, 115쪽 |

### 트리와 산점도의 양방향 연동

4-1 의 핵심입니다. **트리의 노드를 누르면** 산점도에서 그 노드가 담당하는 영역이 강조되고,
**산점도의 아무 곳이나 누르면** 그 자리로 내려가는 트리 경로가 강조됩니다.
"어떤 질문으로 데이터를 나누는가"를 학생이 눈으로 따라갈 수 있습니다.

### 모델 비교실에서 확인되는 것

기본 설정에서 테스트 102개 중 **6개 안팎에서 세 모델의 판단이 갈립니다.**
대부분은 같은 답을 내고, 갈리는 것은 모두 서로 다른 종이 맞닿는 경계 부근입니다.
혼동 행렬의 칸을 누르면 해당 데이터가 세 그래프에서 동시에 강조됩니다.

결정 영역의 모양도 뚜렷하게 다릅니다 — 결정트리는 **계단 모양**,
로지스틱 회귀는 **곧은 직선**, 최근접 이웃은 **들쭉날쭉**합니다.
